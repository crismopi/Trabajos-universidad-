# Gráficos del informe

Una figura en SVG y PNG con título y fuente integrados, además del pie en el informe. Fecha: 21 de octubre de 2026. No se añaden referencias bibliográficas nuevas.

- `01_crecimiento_pib.svg`: cuatro observaciones ya documentadas; años seleccionados separados en dos grupos, sin interpolación ni datos inventados para 2022–2023.

`../datos/elaborados/graficos/datos_grafico_pib.json` guarda la transcripción local de los datos utilizados y sus referencias. No es una descarga de una API. `generar_graficos.py` permite regenerar los SVG con Python 3, sin dependencias externas. La inserción en el informe se realizó una sola vez.
