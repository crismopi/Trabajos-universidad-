## Cómo reverificar

1. Buscar la fuente en el índice y abrir su copia de texto.
2. Usar la URL original para revisar la publicación y su versión vigente.
3. Comprobar año, unidad, tabla y definición antes de reutilizar una cifra.
4. Revisar las diferencias frente a nuevas ediciones; conservar versiones anteriores.
5. Usar `manifest.json` para comprobar procedencia y huella SHA-256. La huella garantiza integridad local, no exactitud de los datos.

La captura es posterior a la consulta inicial: conserva lo que se pudo recuperar ahora y no es una reproducción garantizada de lo visto durante las búsquedas anteriores.
