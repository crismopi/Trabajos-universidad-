# Descargas de fuentes externas

Todavía no hay archivos de datos externos descargados. Las fuentes económicas, institucionales y de vivienda se han consultado mediante herramientas de navegación; sus enlaces están en `../fuentes_consultadas.md`.

Guardar futuras descargas por organismo, conservando el original y usando el patrón `organismo_tema_anio.ext`. Registrar URL, fecha de consulta, periodo del dato y estado de revisión. No confundir un extracto del buscador con un archivo descargado.
