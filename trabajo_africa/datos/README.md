# Datos y fuentes del trabajo sobre Kenia

## Estructura

- `archivo_web/`: copias textuales recuperadas, búsquedas complementarias y manifiesto de integridad; consultar su README para límites y fallos.
- `fuentes_consultadas.md`: índice de fuentes externas citadas en las notas y el borrador, agrupadas por organismo o tema.
- `descargas/`: originales de futuras descargas externas, organizados por organismo. Por ahora solo contiene su README.
- `elaborados/`: futuras tablas depuradas o cálculos, con trazabilidad a sus originales. Por ahora solo contiene su README.

## Estado actual

No hay todavía archivos externos de datos económicos descargados, hojas de cálculo ni una base estadística local. Los datos se consultaron en línea y las referencias están registradas. Ahora se conservan también las extracciones recuperables en `archivo_web/`; no equivalen a los originales completos. No se presentan las notas de investigación como si fueran datos originales.

Los únicos PDF descargados son los materiales docentes del repositorio: `S1.pdf` a `S10.pdf` y la guía del trabajo. Se conservan en la carpeta superior para respetar la estructura del repositorio y mantener los enlaces existentes. No se duplican dentro de datos.

## Convenciones para futuras incorporaciones

1. Guardar el original en `descargas/<organismo>/`, con nombre descriptivo y año de publicación.
2. Registrar URL, fecha de descarga, periodo de los datos y tablas utilizadas.
3. Guardar las transformaciones y cálculos en `elaborados/`, indicando unidades, definiciones y procedimiento.
4. Distinguir datos observados, provisionales, estimaciones de organismos y escenarios propios.
5. Mantener los originales sin editar; no sobrescribir una edición con otra.
