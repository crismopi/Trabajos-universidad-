# Versión Word

`Trabajo_Kenia_Cristina_Moro_APA.docx`: informe con citas autor-fecha y 24 referencias en APA 7, ordenadas alfabéticamente y con sangría francesa. Se conserva únicamente la figura 1, con número, título y nota de fuentes separados. Documento A4, Arial 11, interlineado 1,4 en el cuerpo; las tablas y referencias tienen espaciado adaptado. La petición APA se aplica a las citas y referencias, sin afirmar una maquetación íntegramente APA.

`generar_word_APA.py` conserva el procedimiento. Requiere python-docx y el PNG de la figura APA. Usa como base la copia anterior a APA y sobrescribe el borrador Markdown y el Word. La copia anterior queda en `../datos/revisiones/borrador_antes_APA_2026-10-21.md`.

Ajustes bibliográficos: la página sobre capacidad de pago identifica a Seeta Shah, Zamara y CAHF como autores; el informe colectivo de 2006 se ordena por título al no fijar autoría individual a partir de una lista de colaboradores; UNCTAD 2025a/2025b se distingue por título. El libro de Acemoglu y Robinson se conserva como obra con ficha y extracto editorial consultados, según el registro previo; no se presupone lectura completa. Las referencias estructuradas originales se conservan y la adaptación está en `../datos/revisiones/referencias_APA.json`.

Comprobación de estilo: https://apastyle.apa.org/style-grammar-guidelines/citations/ y https://apastyle.apa.org/style-grammar-guidelines/paper-format/reference-list . No se amplió el número de fuentes del informe.
